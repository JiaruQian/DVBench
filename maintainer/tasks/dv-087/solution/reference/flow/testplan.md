### T-1

feature_ids: F-1
requirement_ids: R-VRP-001
stimulus: Assert rst_sys on the falling edge of a 100MHz clock for 10 edges, then wait 65560 edges after deassertion; reset again during nonzero intensity and attenuation, hold for 5 edges, then repeat the complete wait and check a full frame after startup and clearing.
expected: The clk_100mhz period is 10 ns. rst_sys is active high: system state is reset on the rising edge; the divider reset request is asynchronously loaded into a two-stage synchronizer, and after deassertion, zero is shifted in on each system edge. The divider uses the pre-edge second stage. The divider's internal half-count and pix_clk are cleared on reset; after release, the half-count alternates between 0 and 1, and pix_clk toggles only when the pre-edge half-count is 1, so the pixel clock is 25 MHz. The pixel reset request is also asynchronously loaded into a two-stage synchronizer, with zero shifted in on each pixel rising edge; each pixel state uses the pre-edge second stage. The pixel clock stops during reset, and pixel registers must not be assumed to asynchronously clear to zero; only a reset pixel edge after recovery clears the scan, coordinates, and RGB to zero and sets the sync signals high.

Every system edge with rst_sys high restarts initialization, with the clear address starting at 0; after deassertion, all 65536 addresses are cleared sequentially, and initialization exits on the same edge that clears the final address. Initialization takes priority over all other storage accesses; distance and decay state remain in reset, and hits cannot be accepted. Legal functional inputs must wait at least 65550 system cycles after deassertion. Scanning proceeds independently; stored read values are displayed only after initialization completion has been synchronized through two pixel edges, and intensity is treated as zero before then. Reset may be reapplied during operation, and clearing must be completed again.
checker: The independent, self-contained model/model.sv computes expected using only reset, stimulus, and input history; it does not read DUT outputs. From the start of simulation, the monitor counts every rising edge of the input source clock and samples actual and expected 1ns after the edge; the scoreboard performs four-state comparisons, reports mismatches as UVM_ERROR, and saves the first error and total count. The input source clock is 100MHz clk_100mhz; comparisons are skipped only for the first 40 system rising edges after simulation starts, to allow pixel state without initial values to stabilize. Thereafter, all native outputs are compared on every system rising edge, including during and after a subsequent reset. Skipping 40 edges does not replace the 65550-cycle initialization wait; functional hits are applied strictly after the initialization wait is complete. Check the total number of samples and scan/display output activity; zero comparisons must not pass.

The final decay write request after the busy state ends no longer owns the port, so its commitment is not guaranteed.
