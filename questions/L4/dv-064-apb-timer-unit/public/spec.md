# Dual APB timer peripheral

Verify the complete native dual timer including both32-bit channels,cascade,prescalers,reference sampling and functional clock gates.

### R-p8-timer-001 — Native reset and binary sampling domain

Use APB_ADDR_WIDTH=12. All sequential behavior is based on rising HCLK and asynchronous active-low HRESETn. Reset clears both configurations, compare words, counters, prescaler counts, compare-result pulses, compare pauses and reference-clock sample history to zero. Combinational APB outputs remain functions of the current bus pins during reset. timer_val_lo_o always exposes the low counter. Use known binary inputs stable before each rising HCLK; release reset away from its rising edge. ref_clk_i is an ordinary sampled input, not a second state-update clock. All32-bit data patterns and twelve-bit addresses are legal. The contract includes the supplied clock-gate behavior and parameter value only.

### R-p8-timer-002 — APB access, exact address decode and errors

An access is active whenever PSEL and PENABLE are both one; PREADY is exactly their conjunction, independent of write/read, reset or address validity. Each active write is applied on its HCLK edge, with no requirement that a prior setup edge was recorded. Repeated access edges repeat the operation. The legal byte addresses are0x400,0x404,0x408,0x40c,0x410,0x414,0x418,0x41c,0x420 and0x424. Other addresses, including misalignment, produce PSLVERR during an active access. A legal read returns its register combinationally; legal writes and inactive accesses return PRDATA zero. Either an illegal read or illegal write returns PRDATA0xdeadbeef and PSLVERR one. Inactive accesses always have PSLVERR zero and PRDATA zero.

### R-p8-timer-003 — Register map and stored configuration fields

Addresses0x400/404 are low/high configuration,408/40c are low/high elapsed values,410/414 are low/high compare values,418/41c are low/high start commands,420/424 are low/high reset commands. Configuration and compare registers are readable and writable full32-bit words. Command registers read zero and act on any write regardless of PWDATA. Configuration bit0 enables counting,1 requests counter/prescaler reset,2 enables IRQ,3 permits the input start event,4 enables compare-clear,5 enables one-shot,6 enables prescaling,7 selects sampled reference ticks,15:8 selects the divider threshold and31 is the cascade-mode bit. All other configuration bits remain stored/readable. Low configuration bit31 controls the global32/64-bit counting and IRQ mode; high bit31 separately influences the high one-shot rule. A written reset-request bit acts on a later edge using stored configuration and then clears itself when the corresponding counter reset condition is active.

### R-p8-timer-004 — Elapsed-counter priority and compare pause

Each elapsed counter is32bits and wraps modulo2^32. On an active counter-clock edge form a proposed value with priority: counter reset gives zero; otherwise an elapsed-register write gives PWDATA; otherwise an enabled count tick gives old value plus one; otherwise retain the old value. A previously scheduled compare pause prevents this proposed value from replacing the counter for one enabled tick, except reset or explicit elapsed write overrides the pause. A qualifying compare is an enabled tick, no previous pause, and proposed value equal to the stored compare word. That event registers a reached pulse and schedules the one-tick pause. A previous pause clears on an enabled tick; reset or elapsed write also clears it. Compare detection still uses the proposed reset/write value when a count tick is enabled. Each active clock edge without a qualifying compare clears that channel reached pulse; a closed counter clock retains it. Counter reset has priority over an elapsed write on the same edge.

### R-p8-timer-005 — Independent32-bit mode, IRQ and busy

When low configuration bit31 is zero, each channel uses its own configuration. An enabled channel without prescaling increments on every HCLK counter edge if reference selection is zero, or only on its sampled-reference rise pulse otherwise. With prescaling selected, elapsed-counter tick is the old registered prescaler-reached pulse; it is not additionally gated by the current reference pulse. irq_lo_o and irq_hi_o are each their own registered reached pulse AND stored IRQ-enable AND stored counting-enable. IRQs are transient level outputs, not sticky software status. busy_o is the OR of the two stored counting-enable bits, even when reference ticks are absent. Disabling one channel does not disable or clear the other.

### R-p8-timer-006 — Prescaler recurrence and reference history

ref_clk_i passes through four HCLK samples reset to zero. For a counter edge the reference-rise pulse is true when the sample from two HCLK edges earlier was one and the sample from three edges earlier was zero; a delayed-rise pulse uses the samples from three and four edges earlier. Prescaler tick is channel-enable AND prescaler-enable AND either reference-rise or constant one according to reference selection. Its threshold is configuration bits15:8, plus one when reference mode is selected. On each active channel clock edge its proposed count is zero if explicit prescaler reset or its old reached pulse is true; otherwise add one for a prescaler tick, or hold. Its new reached pulse is true exactly when that proposed count is at least the threshold and a prescaler tick is enabled. Otherwise it clears. Explicit counter reset/reset-command requests reset the prescaler too, but if prescaling and old prescaler-reached are both one, the explicit prescaler-reset decision is replaced by reference-rise in reference mode or by one otherwise. Threshold zero,threshold255 and changing configurations are legal.

### R-p8-timer-007 — Start-event, software-write and one-shot priority

Configuration writes first provide a candidate word. For each channel, a start-command write or its event input high with the candidate event-enable bit3 set forces candidate enable bit0 to one, taking priority over one-shot stop. Otherwise the low channel stops when candidate low one-shot is one and old low reached is one, additionally requiring old high reached when stored low cascade mode is one. The high channel stops if stored high bit31 is zero and candidate high one-shot and old high reached are one; otherwise it also stops when the candidate low one-shot and both old reached pulses are one. These rules apply to candidate configuration after a bus write, so events can override an attempted software disable on the same edge. Finally a counter-reset condition clears that channel candidate reset-request bit1. Start commands change enable but do not clear counter/prescaler state.

### R-p8-timer-008 — Compare-clear and reset commands

A stored config reset-request bit1 or that channel reset-command write resets its counter and requests prescaler reset. Otherwise in32-bit global mode each channel resets its counter when its own stored compare-clear bit4 and old reached pulse are one. In64-bit mode both counters instead reset together when low stored compare-clear and both old reached pulses are one. Compare-clear does not itself reset the prescaler. Low/high reset commands are independent even in cascade mode, do not clear stored configuration or compare values, and do not disable counting. Configuration reset bits are cleared by any active corresponding counter-reset condition.

### R-p8-timer-009 — 64-bit cascade and combined interrupt

When stored low enable and low bit31 are both one, low counting follows the low tick source. High elapsed tick is overridden: without low prescaling/reference it ticks when old low value is0xffffffff; with low prescaling require low old prescaler-reached too; with low reference selection require the delayed reference-rise pulse too. The high own counting-enable is not required for this overridden tick. If low cascade mode is one but low enable is zero, the high counter can still follow its own independent tick logic. In64-bit mode irq_hi_o is always zero and irq_lo_o requires both old/current registered reached pulses, low IRQ-enable and low enable simultaneously; equality of the concatenated elapsed value alone does not substitute for these pulses. busy still ORs both stored enables.

### R-p8-timer-010 — Functional clock gates and DFT force

The low counter clock opens for low counter reset,low elapsed write or stored low enable. The high opens for corresponding high reset/write/high enable, or enabled low cascade mode. These enables are latched while HCLK is low by the supplied gate; dft_cg_enable_i one forces both gates open. Configuration,compare registers and reference samples still update on every HCLK regardless of gates. Elapsed/prescaler counts,compare pauses and reached pulses update only on their channel clock, or asynchronous reset. Consequently an idle closed clock retains its pulse/history; DFT force may clear or change such retained histories according to the same tick/reset rules, rather than acting as an ignored input. Drive gate-affecting bus/control inputs with legal setup before rising HCLK.
